### 🚀 About Me

I am an ECE undergraduate at **PES University, Bengaluru**, specializing in **Native Android Development** and **Computer Vision / AI-ML**. I focus on building practical, high-performance systems — from offline-first mobile applications to audio-visual deep learning models and privacy-preserving federated AI pipelines.

- 📱 **Mobile Development**: Building native Android apps using **Kotlin**, **Jetpack Compose**, **Room DB**, and **Firebase**.
- 🤖 **Machine Learning & Computer Vision**: Working on object detection (**YOLOv5s/v8s**), audio-visual foley generation, and explainable AI (**Grad-CAM/SHAP**).
- 🛠️ **Hardware & Systems**: Academic exposure to drone system architecture (TiHAN IIT Hyderabad), flight modeling (MATLAB/XFLR5), and RISC-V assembly.
- 🎓 **Education**: B.Tech in ECE @ PES University (2023–Present).
